# S3 Resource Operator

S3 Resource Operator manages S3 users and buckets declaratively through Kubernetes custom resources.

The project currently exposes the `s3.dajudge.com/v1alpha1` API and supports VersityGW as its provider.

## Start here

- [Getting started](getting-started.md) walks through installation and the first backend, user, and bucket.
- [CRD API reference](reference/crds.md) is generated from the exact CRDs shipped in the Helm chart.

The project is pre-1.0. Breaking API changes may occur in `0.x` releases and will be documented with upgrade guidance.
